TIMETABLE ADMIN

DMRC Line 7 — administration console. Enter the passphrase to manage timetable metadata, WEF dates and service analysis.

Default passphrase dmrc7 — change it by editing PW_HASH in l7-admin-template.html and rebuilding.

This gate is a user-interface lock, not security. Anyone holding this file can read the passphrase out of it. Real protection means serving the file behind a login.

TIMETABLE METADATA

These fields are what the end user sees in the header of the mimic: which timetable is in force, and the WEF (“with effect from”) date it came into force. The timetable services themselves are baked in at build time by extract.py — this screen cannot change them.

TIMETABLES

BUILD CONFIG

Download l7-meta.json and drop it beside extract.py to make these values the new defaults for the next build.

DATE PROGRAMME

Assign a timetable to a specific date. A programmed date always wins over the automatic weekday / Saturday / Sunday rule, so this is how a Sunday service or a special holiday timetable ever gets shown. The end user cannot change any of this — there is no selector on their view, they only ever see which timetable is running. Press build on the export tab to push these into the file.

UPLOAD TIMETABLE FILE

Load a Line 7 working timetable .xlsx and rebuild the board from it. The file is read inside this page — nothing is uploaded anywhere, and the page keeps working offline. Every sheet is listed with the timetable it maps to; you confirm what was extracted before any of it reaches the end user.

CHOOSE A WORKBOOK

Only .xlsx is supported. .xls is the old binary format and cannot be read here. Password-protected workbooks are not supported.

SERVICE GAPS / HEADWAYS

Every booked call at every station, sorted along the corridor. The gap between consecutive calls is the headway a passenger actually experiences. Long gaps are under-service; very short gaps mean two trains are close together on the same platform.

STATION TIMELINE — ONE TICK PER BOOKED CALL

within both limits over the under-served limit, or under the tight limit over 2x the under-served limit last call of the day, no following headway marker = every 10th station

Each tick is one booked call. A tick is coloured by the gap to the next call at the same station in the same direction, so the last tick of the day is grey by definition. Hover any tick for its exact time and the gap that follows it.

GAP DISTRIBUTION

TRAINS IN SERVICE AT THE START OF EACH 15 MINUTE BUCKET

A train is counted in the bucket its departure falls into, so this is a point-in-time count and will be higher than the instantaneous count shown on the mimic for the same moment. It answers “how many trains are on the line at a given quarter hour”, not “how many stops happen in that quarter hour”.

EXPORT END-USER FILE

The admin console rebuilds the end-user page with the metadata above baked in, then hands you the file. That file still opens straight from disk with no network. When this build is configured with online sync, you can also publish it to Supabase, and every end-user viewer that is online picks it up with no redeploy — the copy baked into the file stays as the offline fallback.
